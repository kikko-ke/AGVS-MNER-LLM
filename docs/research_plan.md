# 研究计划

## 研究假设

多图像 MNER 的难点不是单张图像识别，而是判断哪一张图对哪一个实体提供证据。多模态大模型擅长输出这种语义判断，但直接生成 BIO 标签会有边界不稳定和推理成本高的问题。因此本项目把 LLM 放在教师位置，把 AGVS 放在可部署的学生位置。

## 可验证的问题

1. LLM token 蒸馏是否改善实体边界和长尾类别？
2. LLM 的图像证据分数是否能让学生更准确地选择相关图像 patch？
3. 视觉语言教师相对纯文本教师的增益是否来自图像证据，而不是语言先验？
4. 学生在减少图像数量、打乱图像顺序和替换无关图像后是否保持稳定？
5. 教师置信度过滤、温度和蒸馏权重如何影响收益？

## 必做消融

| 实验 | token 蒸馏 | image 蒸馏 | 目的 |
| --- | ---: | ---: | --- |
| AGVS | 否 | 否 | 原始基线 |
| LLM-token | 是 | 否 | 测量语言语义增益 |
| LLM-image | 否 | 是 | 测量跨图像证据增益 |
| Full | 是 | 是 | 完整方案 |
| Text-teacher | 是 | 否 | 纯文本教师对照 |
| VLM-teacher | 是 | 是 | 多模态教师对照 |

每组报告整体 P/R/F1、实体类型 F1、1/2/3/4 张图的 F1、图像顺序扰动下的下降幅度和推理吞吐。
