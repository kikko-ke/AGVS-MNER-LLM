# 固定 Dropout 一致性后的选样对照

## 之前的结果

2026-11-01 的 MI 内部开发小试验已完成，训练 seed=1234、内部划分
seed=20261101：原始训练 F1=0.8050，Dropout 一致性=0.8111，LLM 改写
一致性=0.8103。LLM 相对原始训练约 +0.53 个百分点，相对 Dropout 约
-0.08 个百分点，未通过相对两个控制均至少 +0.003 的继续门槛。
报告在服务器 `outputs_context_internal/pilot_20261101_224229.json`。
按原规则停止这版改写一致性，不扫权重，不扩展 UNI。

Dropout 控制仍共享 LLM+校验器选出的 179 个可用源样本。新问题限定为：
**同样的原句 Dropout 一致性训练中，联合选样是否优于相同测量特征的
匹配选样？** 这是看到前述结果后的探索性假设，不是独立确认。先前官方
测试负结果仍有效，不将新内部开发成绩改写成最终测试增益。

## 两组与匹配门槛

复用同一内部划分和已有 MI 投影缓存，不生成缓存，不读官方 val/test。
参考 cohort 沿用上一轮内部训练中可对齐的源样本（服务器为 179 个）；
匹配候选来自同一原候选池的内部训练部分，且原句中至少有一个完整保留
的实体。内部 dev 的缓存响应内容与状态不参与选择。

两组固定 `consistency-mode=dropout`，每个原始训练样本每轮一次。对选中
样本使用原句的两个独立随机前向，不输入生成文本。**两组都重新训练**：
这次实体位置一律从原句计算，跳过截断实体；不再按改写的长度过滤。因此
不能直接复用旧 Dropout checkpoint/F1 作为这次的治疗臂。

匹配复用既有固定算法：图片来源域、完整实体类型集合、实际可解码图片数
及截断后完整实体类型集合精确分层；原词/WordPiece 长度、各类实体数、
长度与实体数分箱、完整保留实体数及实体词数作数值匹配。候选打分只使用
原训练字段；参考配额和特征均值来自联合选样。允许两组重叠，不以排除
参考 ID 来人为削弱控制。

固定匹配 seed=20261102、50,000 次 feature swaps；最大候选池 SD 标准化
均值差不超过 0.10，参考/匹配重叠比例不超过 0.80。失败就保存诊断并停止，
不重抽 seed 直到通过。`dropout_cohorts_seed20261102.json` 绑定源数据、
内部划分、缓存/metadata、tokenizer 文件、图片 hash、两组 ID、源实体位置
与权重。训练前校验这些绑定以及样本不跨内部边界。

每个选中样本的实体权重和为 1，按原 batch 大小平均 KL；两组每轮新增
前向的样本数相同，实际额外 batch 数及最终 early-stopping 轮数可能不同。
辅助 RNG 隔离保持主训练随机数流。其余设置沿用上次：seed1234，warmup
2 epochs，weight=0.5，T=2，15 epochs 上限、patience=3、batch=4 等。
只改变样本选择策略。

## 命令和输出

有 GPU 的 AutoDL 项目根目录执行：

```bash
bash scripts/train_dropout_selection_pilot.sh
```

先准备并审计 cohort，通过后前台串行训练 `llm_selected`、`feature_matched`
两组，结束后在同一内部 dev 上重新前向核验原生 CRF 最佳分数。

- 日志：`logs/dropout_selection_*.log`。
- 模型：`outputs_dropout_selection_internal/{arm}_seed1234/mi_*/`。
- 汇总：`outputs_dropout_selection_internal/selection_pilot_*.json`。

同一命令再次执行时，已完整训练且 hash/固定配置校验通过的组会跳过。
未完成的非空输出会报错，保留已有产物排查；不提供 epoch 续训或自动
重跑挑选结果。两组未完成不会生成比较报告。

LLM 联合选样相对匹配组至少 +0.003 才考虑其他种子复验，否则停止此
假设。该工程门槛不是显著性检验，单种子通过也不能宣称稳定提升。接受
状态同时受 LLM 和程序校验器影响，匹配控制也依赖参考群体的聚合特征，
所以该比较不能证明 LLM 语义质量或无条件的因果增益。
