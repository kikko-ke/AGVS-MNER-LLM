## 结论边界

1. 新组件没有通过两数据集的测试泛化验证，应保留为失败消融，不能用 UNI
   validation 的约 +0.27 个百分点宣称最终性能提高。实现测试通过与泛化提升
   是不同结论。
2. 原组件联合选样在 UNI 上仅观察到 +0.128 个百分点平均测试差值，在 MI 上
   为 -0.647，且 MI 三个种子都低于严格基线。不支持“两数据集引入 LLM 均提升”。
3. 选样优于特征匹配控制，不能替代与严格基线的比较：MI 两种重采样的平均
   测试分数都低于不重采样的严格基线。
4. acceptance 由 LLM 生成与校验器共同决定，不是已验证的多模态语义质量。
   新组件尚无同架构匹配组，不能跨架构相减后分离 LLM 独立贡献。
5. 三种子的离散度不是显著性检验。UNI test 早期已用于开发，当前为事后
   补充报告；MI/UNI 的数据和缓存复用也不能被视为完全独立复现。

当前两条路线均不支持跨数据集统一性能提升的结论。完整保存负结果、固定
模型和数据绑定，不根据这些测试分数继续选择权重、种子或组件开关。后续
方法开发应建立新的训练集内部开发协议或独立封存的数据评估，并说明历史。
